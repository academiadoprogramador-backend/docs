Serialização JSON

Até agora, trabalhamos apenas com dados armazenados em memória durante a execução do programa.

Isso significa que listas de categorias, produtos e listas de compras eram perdidas ao fechar o terminal.

Nesta aula, vamos aprender o primeiro passo para resolver esse problema.

Vamos entender como converter objetos em um formato que possa ser salvo e recuperado depois.

Esse processo se chama serialização.

O que é serialização?​

Serialização é o processo de converter um objeto em memória para um formato que possa ser armazenado ou transmitido.

No sentido inverso, a desserialização é o processo de ler esse formato e reconstruir o objeto em memória.

Visualizando o processo:

Objeto em memória
      |
      v
   Serialização
      |
      v
Formato para armazenamento

E o caminho inverso:

Formato para armazenamento
      |
      v
  Desserialização
      |
      v
Objeto em memória

Existem vários formatos de serialização.

O que vamos usar é o JSON.

O que é JSON?​

JSON (JavaScript Object Notation) é um formato de texto usado para representar dados estruturados.

Ele é:

  • leve;
  • legível por humanos;
  • suportado por praticamente todas as linguagens de programação.

Um exemplo de JSON:

{
  "id": 1,
  "nome": "Padaria",
  "produtos": []
}

Esse formato representa um objeto com propriedades e valores.

Cada propriedade tem:

  • um nome entre aspas;
  • dois pontos;
  • um valor.

Os valores podem ser:

  • texto ("Padaria");
  • número (1);
  • booleano (true ou false);
  • array ([]);
  • outro objeto ({});
  • nulo (null).

System.Text.Json​

O .NET oferece uma biblioteca pronta para trabalhar com JSON.

Ela se chama System.Text.Json e está disponível desde o .NET Core 3.0.

Os principais recursos que vamos usar são:

  • JsonSerializer.Serialize — converte um objeto para JSON;
  • JsonSerializer.Deserialize<T> — converte JSON de volta para um objeto;
  • JsonSerializerOptions — configura o comportamento da serialização.

Para usar a biblioteca, precisamos adicionar o using no início do arquivo:

using System.Text.Json;

Serializando um objeto​

Vamos começar com um exemplo simples.

Temos uma classe que representa uma categoria:

public class Categoria
{
    public int Id { get; set; }
    public string Nome { get; set; }
}

Para converter um objeto dessa classe para JSON:

Categoria categoria = new Categoria();
categoria.Id = 1;
categoria.Nome = "Padaria";

string json = JsonSerializer.Serialize(categoria);

Console.WriteLine(json);

A saída será:

{"Id":1,"Nome":"Padaria"}

Repare que:

  • as propriedades públicas da classe foram convertidas para JSON;
  • o nome da propriedade virou a chave no JSON;
  • o valor da propriedade virou o valor no JSON.

Desserializando um objeto​

Para fazer o caminho inverso, usamos Deserialize<T>:

string json = "{\"Id\":1,\"Nome\":\"Padaria\"}";

Categoria? categoria = JsonSerializer.Deserialize<Categoria>(json);

Console.WriteLine(categoria?.Nome);

Aqui estamos dizendo:

"leia esse texto JSON e tente transformá-lo em um objeto do tipo Categoria."

O T entre < e > informa qual tipo queremos como resultado.

O ? depois de Categoria indica que o resultado pode ser null.

Se o JSON for inválido ou incompatível, o método retorna null.

Formatando a saída​

Por padrão, o JSON gerado fica em uma única linha:

{"Id":1,"Nome":"Padaria"}

Isso é compacto, mas difícil de ler.

Podemos usar JsonSerializerOptions para deixar a saída mais legível:

JsonSerializerOptions options = new JsonSerializerOptions();
options.WriteIndented = true;

string json = JsonSerializer.Serialize(categoria, options);

Agora a saída será:

{
  "Id": 1,
  "Nome": "Padaria"
}

Cada propriedade aparece em uma linha separada, com indentação.

Isso facilita a leitura do conteúdo salvo.

Serializando listas​

A serialização também funciona com coleções.

List<Categoria> categorias = new List<Categoria>
{
    new Categoria { Id = 1, Nome = "Padaria" },
    new Categoria { Id = 2, Nome = "Hortifrúti" }
};

JsonSerializerOptions options = new JsonSerializerOptions();
options.WriteIndented = true;

string json = JsonSerializer.Serialize(categorias, options);

O resultado será:

[
  {
    "Id": 1,
    "Nome": "Padaria"
  },
  {
    "Id": 2,
    "Nome": "Hortifrúti"
  }
]

Uma lista de objetos vira um array JSON.

Referências circulares​

Em objetos que possuem referências mútuas, o serializador padrão pode lançar um erro.

Por exemplo:

public class Categoria
{
    public List<Produto> Produtos { get; set; }
}

public class Produto
{
    public Categoria Categoria { get; set; }
}

Uma categoria tem uma lista de produtos.

Um produto tem uma referência para a categoria.

Isso cria uma referência circular:

Categoria -> Produtos -> Produto -> Categoria -> ...

O serializador padrão não consegue lidar com isso.

Para resolver, usamos ReferenceHandler.Preserve:

JsonSerializerOptions options = new JsonSerializerOptions();
options.WriteIndented = true;
options.ReferenceHandler = ReferenceHandler.Preserve;

Com essa opção, o JSON gerado inclui identificadores para cada objeto, preservando as referências.

{
  "$id": "1",
  "Produtos": [
    {
      "$id": "2",
      "Categoria": {
        "$ref": "1"
      }
    }
  ]
}

Quando desserializamos, as referências são restauradas automaticamente.

Boas práticas com serialização​

Alguns cuidados importantes ao trabalhar com serialização:

  • serializar apenas propriedades públicas;
  • evitar referências circulares, ou usar ReferenceHandler.Preserve;
  • tomar cuidado com objetos grandes, pois o JSON pode ficar pesado;
  • usar WriteIndented para depuração, mas manter compacto para produção se necessário.

Conexão com os próximos passos​

A serialização é o mecanismo que permite converter objetos para JSON.

Mas, por si só, ela não resolve o problema de manter dados entre execuções.

Para isso, precisamos salvar esse JSON em um arquivo no disco.

Esse será o tema da próxima aula.

Conclusão​

Serialização JSON é o processo de converter objetos em texto no formato JSON.

O System.Text.Json do .NET oferece ferramentas prontas para isso.

Em resumo:

  • JsonSerializer.Serialize converte objeto para JSON;
  • JsonSerializer.Deserialize<T> converte JSON para objeto;
  • JsonSerializerOptions permite configurar a serialização;
  • WriteIndented formata a saída para leitura;
  • ReferenceHandler.Preserve resolve referências circulares.

Com a serialização, conseguimos transformar objetos em um formato que pode ser salvo, enviado ou armazenado.

No próximo documento, vamos usar esse JSON para persistir dados em arquivo.
