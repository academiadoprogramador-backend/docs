Estilização com Bootstrap

Estilização de Views com Bootstrap​

Nas aulas anteriores, criamos:

  • Controllers;
  • Views;
  • Layouts;
  • ViewModels;
  • formulários;
  • tabelas e links com TagHelpers.

Com isso, a aplicação já funciona.

Porém, uma View pode funcionar e ainda ser difícil de ler ou usar.

Um formulário sem espaçamento pode ficar confuso.

Uma listagem sem organização visual pode dificultar a localização das informações.

Um menu sem adaptação para telas pequenas pode deixar a aplicação ruim de utilizar no celular.

Para resolver parte desses problemas, podemos utilizar o Bootstrap.

O que é Bootstrap?​

Bootstrap é um framework de CSS e JavaScript para criação de interfaces web.

Ele oferece classes prontas para:

  • espaçamento;
  • cores;
  • botões;
  • formulários;
  • tabelas;
  • cards;
  • menus;
  • alertas;
  • organização responsiva da página.

Em vez de criar todo o CSS desde o início, utilizamos classes que já possuem estilos definidos.

Por exemplo, um botão HTML comum pode ser escrito assim:

<button type="button">Salvar</button>

Esse botão funciona, mas não possui uma aparência definida pelo Bootstrap.

Para utilizar o estilo de botão do Bootstrap, adicionamos classes:

<button class="btn btn-primary" type="button">Salvar</button>

Nesse exemplo:

  • btn indica que o elemento deve ter aparência de botão;
  • btn-primary aplica a cor principal do tema.

Bootstrap não substitui o HTML, o Razor ou o ASP.NET MVC. Ele fornece estilos e comportamentos prontos para elementos que já fazem parte da View.

Adicionando o Bootstrap ao Layout​

Como o Bootstrap será utilizado em várias páginas, o melhor lugar para adicioná-lo é o Layout.

No projeto de referência, o arquivo utilizado é:

Views/Shared/_Layout.cshtml

O Layout é aplicado às Views e evita que cada página precise repetir a mesma estrutura HTML.

Para carregar o Bootstrap, adicionamos o CSS dentro da tag <head>:

<link
    href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
    rel="stylesheet"
    integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB"
    crossorigin="anonymous"
>

Esse código carrega o arquivo CSS do Bootstrap por meio de uma CDN.

CDN é uma rede de servidores que disponibiliza arquivos para serem carregados pela aplicação.

Depois de carregar o CSS, as classes do Bootstrap passam a ser reconhecidas pelo navegador.

O viewport em telas pequenas​

Também precisamos garantir que o navegador utilize corretamente a largura do dispositivo:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Essa configuração é importante para que a página se adapte a celulares e tablets.

Sem ela, o navegador pode tratar a página como se tivesse uma largura maior do que a tela física.

Uma estrutura inicial do Layout pode ser:

<!DOCTYPE html>
<html lang="pt-BR">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">

        <title>@ViewBag.Titulo | Controle de Medicamentos</title>

        <link
            href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
            rel="stylesheet"
            integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB"
            crossorigin="anonymous"
        >
    </head>
    <body>
        @RenderBody()
    </body>
</html>

O @RenderBody() continua sendo o local onde o ASP.NET insere o conteúdo da View atual.

A diferença é que agora essa View pode utilizar as classes do Bootstrap.

Containers​

Uma página pode ocupar toda a largura da tela e ficar difícil de acompanhar.

O Bootstrap possui a classe container para limitar e centralizar o conteúdo.

<main class="container">
    <h1>Controle de Medicamentos</h1>
    <p>Gerencie os dados da aplicação.</p>
</main>

No projeto de referência, o conteúdo principal do Layout utiliza:

<main class="container py-4">
    <header class="mb-4">
        <h1>@ViewBag.Titulo</h1>
    </header>

    @RenderBody()
</main>

Nesse trecho:

  • container centraliza e limita a largura do conteúdo;
  • py-4 adiciona espaçamento vertical interno;
  • mb-4 adiciona margem abaixo do cabeçalho.

Classes de espaçamento​

As classes de espaçamento seguem uma convenção.

As letras indicam o tipo de espaçamento:

  • m, para margem;
  • p, para espaçamento interno, chamado de padding;
  • t, para o topo;
  • b, para a parte inferior;
  • s, para o início horizontal;
  • e, para o fim horizontal;
  • x, para os dois lados horizontais;
  • y, para os dois lados verticais.

O número indica o tamanho do espaçamento.

Exemplos:

<div class="mt-4">Margem no topo</div>
<div class="mb-3">Margem abaixo</div>
<div class="px-2">Espaçamento horizontal interno</div>
<div class="py-4">Espaçamento vertical interno</div>

Essas classes evitam a criação de pequenas regras CSS para cada margem ou padding.

Botões​

Para criar um botão do Bootstrap, usamos a classe btn junto com uma classe de cor.

<button class="btn btn-primary" type="submit">Cadastrar</button>
<button class="btn btn-secondary" type="button">Cancelar</button>
<button class="btn btn-danger" type="button">Excluir</button>

Algumas variações comuns são:

  • btn-primary, para uma ação principal;
  • btn-secondary, para uma ação secundária;
  • btn-success, para uma operação concluída ou positiva;
  • btn-danger, para uma ação destrutiva;
  • btn-outline-primary, para uma versão com fundo transparente.

Também podemos criar botões menores:

<a class="btn btn-sm btn-outline-primary" href="#">Editar</a>
<a class="btn btn-sm btn-outline-danger" href="#">Excluir</a>

O Bootstrap pode estilizar tanto <button> quanto links <a>.

Isso é útil porque um link pode representar navegação e ainda possuir aparência de botão.

Bootstrap e TagHelpers​

As classes do Bootstrap podem ser utilizadas junto com os TagHelpers.

Por exemplo, um link integrado ao MVC pode ser escrito assim:

<a class="btn btn-primary" asp-action="Cadastrar">
    Cadastrar fornecedor
</a>

O atributo asp-action continua sendo processado pelo ASP.NET.

A classe btn btn-primary apenas altera a aparência do link.

O resultado final mantém as duas responsabilidades:

  • TagHelper, para gerar a navegação;
  • Bootstrap, para aplicar o estilo.

Estilizando formulários​

Um formulário HTML simples pode ser difícil de ler quando todos os campos ficam próximos.

O Bootstrap fornece classes para labels e inputs.

<form>
    <div class="mb-3">
        <label class="form-label" for="Nome">Nome</label>
        <input class="form-control" id="Nome" name="Nome" type="text">
    </div>

    <div class="mb-3">
        <label class="form-label" for="Telefone">Telefone</label>
        <input class="form-control" id="Telefone" name="Telefone" type="text">
    </div>

    <button class="btn btn-primary" type="submit">Cadastrar</button>
</form>

Nesse exemplo:

  • form-label melhora a apresentação do label;
  • form-control aplica o estilo e a largura adequada ao input;
  • mb-3 separa os campos verticalmente.

As mesmas classes funcionam com asp-for:

@model CadastrarFornecedorViewModel

<form asp-action="Cadastrar" method="post">
    <div class="mb-3">
        <label class="form-label" asp-for="Nome"></label>
        <input class="form-control" asp-for="Nome" type="text">
    </div>

    <div class="mb-3">
        <label class="form-label" asp-for="Telefone"></label>
        <input class="form-control" asp-for="Telefone" type="text">
    </div>

    <button class="btn btn-primary" type="submit">Cadastrar</button>
</form>

O asp-for continua ligando os campos à ViewModel.

O Bootstrap apenas adiciona as classes visuais.

Limitando a largura do formulário​

Em telas grandes, um formulário que ocupa toda a largura pode ficar desconfortável.

Podemos combinar o sistema de colunas com o formulário:

<div class="row justify-content-start">
    <form class="col-lg-6" asp-action="Cadastrar" method="post">
        <div class="mb-3">
            <label class="form-label" asp-for="Nome"></label>
            <input class="form-control" asp-for="Nome" type="text">
        </div>

        <button class="btn btn-primary" type="submit">Cadastrar</button>
    </form>
</div>

A classe col-lg-6 indica que, em telas grandes, o formulário ocupará metade da linha.

Em telas menores, ele pode ocupar toda a largura disponível.

Essa é uma das características do design responsivo do Bootstrap.

Sistema de linhas e colunas​

O Bootstrap organiza o conteúdo com row e col.

<div class="row">
    <div class="col">
        Conteúdo da primeira coluna
    </div>

    <div class="col">
        Conteúdo da segunda coluna
    </div>
</div>

Quando as colunas possuem a mesma classe col, o espaço disponível é dividido entre elas.

Também podemos indicar diferentes comportamentos para cada tamanho de tela:

<div class="row">
    <div class="col-12 col-lg-6">
        Texto da página
    </div>

    <div class="col-12 col-lg-6">
        Imagem da página
    </div>
</div>

Nesse caso:

  • col-12 faz o bloco ocupar toda a linha em telas pequenas;
  • col-lg-6 faz o bloco ocupar metade da linha em telas grandes.

Podemos adicionar espaço entre as colunas usando gap-3 ou g-3:

<div class="row gap-3 gap-lg-0">
    <div class="col">
        Conteúdo
    </div>

    <div class="col-12 col-lg-6">
        Imagem
    </div>
</div>

O sufixo -lg-0 permite remover o espaço a partir do tamanho de tela lg.

Cards​

Cards são blocos visuais usados para agrupar informações relacionadas.

<div class="card">
    <div class="card-body">
        <h5 class="card-title">Dipirona</h5>
        <p class="card-text">Medicamento disponível no estoque.</p>
        <a class="btn btn-primary" href="#">Visualizar</a>
    </div>
</div>

No projeto de referência, cada fornecedor é exibido dentro de um card:

<div class="card h-100">
    <div class="card-body">
        <div class="d-flex justify-content-between align-items-center mb-2">
            <h5>@f.Nome</h5>
            <span class="badge text-bg-secondary">@f.Id</span>
        </div>

        <dl class="row mb-2">
            <dt class="col-sm-4">Telefone</dt>
            <dd class="col-sm-8">@f.Telefone</dd>

            <dt class="col-sm-4">CNPJ</dt>
            <dd class="col-sm-8">@f.Cnpj</dd>
        </dl>
    </div>
</div>

Nesse exemplo:

  • card cria o contêiner visual;
  • card-body adiciona a área interna do card;
  • h-100 faz os cards da mesma linha ocuparem alturas iguais;
  • d-flex ativa o alinhamento flexível;
  • justify-content-between separa o nome e o identificador;
  • align-items-center alinha os elementos verticalmente.

Badges​

Um badge é um pequeno destaque visual para informações curtas.

<span class="badge text-bg-secondary">123</span>
<span class="badge text-bg-success">Disponível</span>
<span class="badge text-bg-danger">Em falta</span>

Ele pode ser usado para mostrar:

  • identificadores;
  • status;
  • categorias;
  • contadores.

No exemplo de fornecedores, o Id aparece ao lado do nome:

<span class="badge text-bg-secondary">@f.Id</span>

O valor continua vindo da ViewModel.

O Bootstrap apenas destaca visualmente esse valor.

Alertas​

Quando uma lista está vazia, podemos informar o usuário com um alerta.

<div class="alert alert-warning" role="alert">
    Não há nenhum fornecedor registrado.
</div>

Algumas variações comuns são:

  • alert-primary;
  • alert-success;
  • alert-warning;
  • alert-danger.

Na View de listagem, o alerta pode ser exibido condicionalmente com Razor:

@if (Model.Count == 0)
{
    <div class="alert alert-warning mt-4" role="alert">
        Não há nenhum fornecedor registrado.
    </div>
}

O Razor decide quando o alerta será exibido.

O Bootstrap define como ele será apresentado.

Organizando uma listagem responsiva​

A View pode percorrer uma lista com foreach e criar um card para cada item.

@model List<ListarFornecedorViewModel>

<div class="row row-cols-1 row-cols-md-2 row-cols-lg-3 row-cols-xl-4 g-3 mt-4">
    @foreach (ListarFornecedorViewModel fornecedor in Model)
    {
        <div class="col">
            <div class="card h-100">
                <div class="card-body">
                    <h5>@fornecedor.Nome</h5>
                    <p>@fornecedor.Telefone</p>

                    <a class="btn btn-sm btn-outline-primary"
                       asp-action="Editar"
                       asp-route-id="@fornecedor.Id">
                        Editar
                    </a>
                </div>
            </div>
        </div>
    }
</div>

As classes row-cols-* definem quantas colunas aparecem em cada tamanho de tela:

  • row-cols-1, uma coluna em telas pequenas;
  • row-cols-md-2, duas colunas a partir de md;
  • row-cols-lg-3, três colunas a partir de lg;
  • row-cols-xl-4, quatro colunas a partir de xl.

Assim, a quantidade de cards se adapta ao espaço disponível.

Menu de navegação​

O Bootstrap também fornece classes para criar menus.

Um menu básico pode ser escrito assim:

<nav class="navbar bg-primary">
    <div class="container">
        <a class="navbar-brand" href="#">Controle de Medicamentos</a>
    </div>
</nav>

Podemos adicionar links ao menu:

<nav class="navbar navbar-expand-lg bg-primary">
    <div class="container">
        <a class="navbar-brand" asp-controller="Home" asp-action="Index">
            Controle de Medicamentos
        </a>

        <div class="collapse navbar-collapse">
            <ul class="navbar-nav">
                <li class="nav-item">
                    <a class="nav-link" asp-controller="Home" asp-action="Index">Início</a>
                </li>

                <li class="nav-item">
                    <a class="nav-link" asp-controller="Fornecedor" asp-action="Listar">
                        Fornecedores
                    </a>
                </li>
            </ul>
        </div>
    </div>
</nav>

As classes navbar, nav-item e nav-link organizam a aparência do menu.

A classe navbar-expand-lg informa que o menu pode mudar de comportamento em telas menores.

Menu responsivo​

Para criar um menu que pode ser expandido no celular, utilizamos um botão e um elemento colapsável:

<nav class="navbar navbar-expand-lg bg-primary">
    <div class="container">
        <a class="navbar-brand" asp-controller="Home" asp-action="Index">
            Controle de Medicamentos
        </a>

        <button
            class="navbar-toggler"
            type="button"
            data-bs-toggle="collapse"
            data-bs-target="#navbarNav"
            aria-controls="navbarNav"
            aria-expanded="false"
            aria-label="Alternar navegação"
        >
            <span class="navbar-toggler-icon"></span>
        </button>

        <div class="collapse navbar-collapse" id="navbarNav">
            <!-- links do menu -->
        </div>
    </div>
</nav>

Os atributos data-bs-toggle e data-bs-target informam qual elemento será expandido ou recolhido.

Esse comportamento depende do JavaScript do Bootstrap.

Por isso, adicionamos o bundle antes do fechamento do <body>:

<script
    src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"
    integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI"
    crossorigin="anonymous"
></script>

Classes como btn, card e form-control dependem principalmente do CSS.

Componentes interativos, como o menu colapsável, também precisam do JavaScript.

Bootstrap Icons​

O projeto de referência também utiliza o Bootstrap Icons.

Ele é carregado com outro arquivo CSS:

<link
    href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.13.1/font/bootstrap-icons.min.css"
    rel="stylesheet"
>

Depois podemos inserir um ícone usando uma classe bi:

<i class="bi bi-check"></i>
<i class="bi bi-pencil"></i>
<i class="bi bi-trash3"></i>

Um botão com ícone pode ser escrito assim:

<button class="btn btn-primary" type="submit">
    <i class="bi bi-check"></i>
    Cadastrar
</button>

O ícone não altera a lógica do botão.

Ele apenas ajuda o usuário a reconhecer a ação.

Tema escuro​

O Bootstrap 5.3 permite informar o tema do documento com data-bs-theme.

No projeto de referência, o tema escuro é habilitado no elemento <body>:

<body data-bs-theme="dark">
    ...
</body>

Esse atributo modifica as cores utilizadas por componentes compatíveis com o tema.

O tema não muda a estrutura da aplicação.

Ele apenas altera a forma como os elementos são exibidos.

O Layout concentra os recursos compartilhados por várias páginas.

As Views ficam responsáveis pelo conteúdo específico de cada tela.

O que muda na View de listagem?​

Antes de aplicar Bootstrap, uma listagem poderia possuir apenas HTML estrutural:

<p>
    <a asp-action="Cadastrar">Cadastrar fornecedor</a>
</p>

<div>
    @foreach (ListarFornecedorViewModel fornecedor in Model)
    {
        <div>
            <h5>@fornecedor.Nome</h5>
            <p>@fornecedor.Telefone</p>
        </div>
    }
</div>

Depois, adicionamos classes visuais sem alterar a lógica do foreach:

<p>
    <a class="btn btn-primary" asp-action="Cadastrar">
        <i class="bi bi-patch-plus"></i>
        Cadastrar fornecedor
    </a>
</p>

<div class="row row-cols-1 row-cols-md-2 row-cols-lg-3 g-3 mt-4">
    @foreach (ListarFornecedorViewModel fornecedor in Model)
    {
        <div class="col">
            <div class="card h-100">
                <div class="card-body">
                    <h5>@fornecedor.Nome</h5>
                    <p>@fornecedor.Telefone</p>

                    <a
                        class="btn btn-sm btn-outline-primary"
                        asp-action="Editar"
                        asp-route-id="@fornecedor.Id"
                    >
                        Editar
                    </a>
                </div>
            </div>
        </div>
    }
</div>

O Controller não precisa ser alterado para essa mudança.

O Model e a ViewModel também continuam representando os mesmos dados.

A alteração está concentrada na apresentação da View.

Bootstrap não substitui a lógica do sistema​

É importante separar as responsabilidades.

O Bootstrap não deve:

  • buscar dados no repositório;
  • validar regras de negócio;
  • cadastrar medicamentos;
  • decidir se um fornecedor pode ser excluído;
  • substituir o Controller;
  • substituir a ViewModel.

Essas tarefas continuam pertencendo às partes correspondentes da aplicação.

O Bootstrap ajuda na camada de apresentação.

Podemos resumir assim:

Controller
    coordena a requisição

ViewModel
    transporta os dados da tela

Razor e TagHelpers
    geram o HTML da View

Bootstrap
    aplica estilos e comportamentos visuais

Observações sobre CDN​

Usar uma CDN é uma forma rápida de adicionar Bootstrap ao projeto.

Ela é adequada para os primeiros exemplos porque não exige configuração de compilação de CSS ou JavaScript.

Porém, a aplicação passa a depender do carregamento de arquivos externos.

Em projetos maiores, também é possível instalar e manter os arquivos localmente.

Neste momento, o mais importante é entender como o CSS é carregado e como suas classes são utilizadas nas Views.

Conclusão​

Bootstrap é um framework que fornece classes prontas para estilizar páginas web.

Ele pode ser adicionado ao _Layout.cshtml para ficar disponível em várias Views.

As classes container, row, col, btn, form-control, card, badge e alert resolvem necessidades comuns da interface.

As classes responsivas permitem adaptar a mesma View para diferentes tamanhos de tela.

Bootstrap também pode ser combinado com:

  • Razor;
  • ViewModels;
  • TagHelpers;
  • Controllers;
  • Layouts.

No projeto de referência, a estilização da aplicação é feita principalmente no Layout e nas Views.

Essa organização mantém a lógica do sistema separada da aparência da interface.

Para consultar o exemplo completo, veja o repositório controle-de-medicamentos-2026, versão v10.
